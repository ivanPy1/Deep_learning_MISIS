# Домашнее задание: PyTorch Lightning

## Описание проекта

Этот проект демонстрирует классификацию вин с использованием PyTorch Lightning. Реализована нейронная сеть для классификации вин на 3 класса по 13 химическим признакам из датасета Wine.

## Что сделано

### 1. Реализация WineDataModule

Создан класс `WineDataModule` для управления данными, который включает:

- Инициализацию тренировочных и тестовых данных
- Настройку датасетов в методе `setup()`
- Создание DataLoader'ов для обучения, валидации и тестирования
- Автоматическую обработку батчей и перемешивание данных

### 2. Реализация NeuralNetLightning

Создан класс `NeuralNetLightning` с полной реализацией всех необходимых методов:

#### `__init__`
- Инициализация архитектуры нейронной сети с тремя линейными слоями
- Настройка функции потерь (CrossEntropyLoss)
- Сохранение гиперпараметров

#### `forward`
- Реализация прямого прохода через сеть

#### `training_step`
- Шаг обучения с вычислением потерь
- Логирование метрик обучения

#### `validation_step`
- Шаг валидации с вычислением потерь и точности
- Логирование метрик валидации

#### `test_step`
- Шаг тестирования с вычислением точности
- Логирование метрик тестирования

#### `configure_optimizers`
- Настройка оптимизатора Adam с заданным learning rate

## Архитектура модели

Нейронная сеть состоит из:
- Входной слой: 13 признаков → 32 нейрона
- Скрытый слой: 32 нейрона → 16 нейронов  
- Выходной слой: 16 нейронов → 3 класса
- Функции активации: ReLU

## Используемые технологии

- **PyTorch Lightning** - фреймворк для упрощения обучения моделей
- **PyTorch** - основной фреймворк для глубокого обучения
- **scikit-learn** - для работы с данными и метрик
- **matplotlib** - для визуализации результатов

## Метрики качества

После обучения модель достигает:
- **Точность на тестовой выборке**: 100%
- **Потери на обучении**: стабильно уменьшаются
- **Сбалансированные метрики** для всех трех классов
